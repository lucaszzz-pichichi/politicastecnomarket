Usuarios Externos

1. Políticas para Clientes

Protección de Cuenta y Compras

Mínimo Privilegio y Alcance

Los clientes pueden registrarse, iniciar sesión, consultar el catálogo de productos, realizar compras electrónicas y revisar únicamente el estado de sus propios pedidos.

Seguridad de Cuenta y Contraseñas

Se exige el uso de contraseñas seguras y personales (nunca compartidas). Las claves nunca se guardan en texto plano, sino mediante funciones de hash seguras.

Privacidad y Navegación Segura

Los datos personales (nombre, dirección, correo e historial de compras) son confidenciales y viajan cifrados mediante protocolo seguro HTTPS.

Prevención ante Riesgos o Sospechas

Ante múltiples intentos fallidos de ingreso o actividad sospechosa, el sistema aplica un bloqueo temporal preventivo y solicita el cambio de credenciales.

Personal de la Empresa

2. Políticas para Empleados y Equipo Interno

Operación Interna e Infraestructura
Empleados

Gestionan pedidos y productos únicamente dentro de sus funciones asignadas.

Administradores

Administren usuarios y configuraciones con MFA obligatorio.

Personal Técnico

Mantenimiento de servidores, bases de datos, código y copias de seguridad.

Control de Acceso y Baja de Personal

Prohibido compartir credenciales entre compañeros. Cuando un empleado deja TecnoMarket, su cuenta y permisos se deshabilitan de inmediato.

Manejo de Datos Confidenciales

Prohibido divulgar datos de clientes sin autorización o copiar información interna y código fuente a dispositivos personales.

Copias de Seguridad (Backups)

Respaldos automáticos, cifrados y alojados fuera del sistema principal, con pruebas de restauración trimestrales a cargo del área técnica.

Gestión de Incidentes

Reporte inmediato obligatorio; prohibido ocultar fallas o borrar evidencias. Flujo: Detectar → Analizar → Contener → Restaurar → Prevenir.
